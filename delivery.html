위캐리 AX v2 · 1차 납품 안내

요청을 계획표로, 승인한 계획을 일시중지 광고로.

관리자는 연결과 권한을 준비하고, 마케터는 계획표와 실행 승인을 확인합니다. 광고를 켜는 일은 각 광고 관리자에서 사람이 직접 합니다.

버전·상태 — v2.0.0-alpha.2 · 1차 납품본, 실기 재확인 전

작성일 2026-11-14 · 대면 설정 예정 2026-11-17 · 스킬 v0.2(PR #10 반영).

확인된 범위: Windows Claude 데스크톱 앱 Chat 탭에서 Google 확장 설치·로그인·일시중지 생성·재조회, Meta 이미지·영상 광고 PAUSED 생성·재조회가 기록되어 있습니다. TikTok은 직접 지시 시험에서 Smart+ 영상 Spark 광고의 캠페인·광고그룹·광고 DISABLE 생성·재조회가 기록되어 있습니다.

확인 필요: Mac 실기 전체, 수정 스킬의 승인 절차 재시험, 최신 확장 설치 후 키워드·통화·일정 재조회, Slack 내부 채널 전송. Google의 위캐리 Workspace 내부용 앱·Explorer·실제 광고 계정, Claude Team 조직 등록은 위캐리 환경에서 확인 전입니다. 기존 Windows 시험은 이전 설치본 기준이며 최신 납품본 전체의 합격을 뜻하지 않습니다.

화면 안내: Chat 탭·“광고 계정 미디어” 등 기록된 화면을 제외하고 실기로 확인되지 않은 메뉴·설정 경로에는 확인 필요를 붙였습니다. 이 문서는 설치·운영 안내 초안이며 최종 납품 수락 기록이 아닙니다.

01

관리자 설치 안내서

위캐리 Owner가 준비합니다. 아래 5단계를 마친 뒤 마케터와 연결 상태를 확인합니다.

01 · Owner 지정과 스킬 등록

  • Claude Team Owner를 지정하고 납품받은 최신 wecarry-ad-setup 스킬 묶음을 조직에 등록합니다.
  • 스킬 등록 메뉴와 조직 배포 경로는 확인 필요입니다. 화면이 다르면 임의로 다른 메뉴를 고르지 말고 납품 담당자와 함께 확인합니다.
  • 마케터의 새 Chat 대화에서 “이 요청 세팅해 줘”가 위캐리 업무 스킬로 처리되는지 확인합니다. 조직 등록·동작 실기는 확인 필요입니다.

02 · 공식 커넥터 연결

  • Notion·Google Drive·Slack·Meta Ads·TikTok for Business를 연결합니다. 연결 메뉴의 정확한 위치는 확인 필요입니다.
  • 마케터는 본인 계정으로 로그인합니다. Notion 요청·제품·브랜드·계정 정보, Drive 소재 폴더, 광고 계정·페이지에 필요한 접근 권한을 확인합니다.
  • Slack은 내부 보고 채널을 정합니다. 외부 공유(Slack Connect) 채널은 이번 시험에서 전송되지 않았습니다.

03 · 위험 도구 차단과 실행 승인 설정

  • TikTok의 상태 변경(*_status_update)·수정(*_update)·예산 변경·bc_create 도구를 차단합니다.
  • TikTok tool_execute는 승인 필요로 둡니다. 범용 실행 안에서도 상태 변경·수정·예산 변경·삭제는 허용하지 않습니다.
  • Meta의 Activate Ads Entity(켜기), Ads update entity(수정), Ads boost ig post(인스타 홍보)를 차단합니다.
  • Claude는 수동 모드, 생성 도구와 tool_execute는 항상 허용 금지입니다. 차단·승인 설정의 메뉴 위치와 표시 이름은 확인 필요이며 마케터별로 확인합니다.

04 · 위캐리 Google Cloud 준비

  • 위캐리 Workspace 조직 하위 Cloud 프로젝트에서 Google Ads API를 사용 설정하고 OAuth 앱을 내부용으로 구성합니다.
  • adwords 범위를 설정하고 데스크톱 앱 유형 OAuth 클라이언트를 준비합니다. 내부용 설정의 실제 화면·경로는 확인 필요입니다.
  • 위캐리 프로젝트의 Google Ads API Explorer 등급을 신청합니다. Test 등급으로는 실제 계정 호출이 막힐 수 있으며 심사 소요 시간은 미공개입니다. 신청 화면 경로는 확인 필요입니다.
  • 클라이언트 값과 비밀값은 확장 설치 설정에만 입력합니다. 채팅·문서·Notion·Slack에 붙이지 않습니다.

05 · Google 확장 배포와 설치값 확인

  • 납품받은 wecarry-google-ads.mcpb를 마케터에게 전달합니다. Mac·Windows가 같은 파일을 사용하지만 Mac 실기는 확인 필요입니다.
  • 설치 시 광고 계정, 관리자(MCC) 계정(해당하는 경우), OAuth 클라이언트 값을 입력합니다. 설치 1회는 광고 계정 1개에 연결됩니다.
  • 설정 항목명은 Google Ads customer ID, Manager (MCC) customer ID, OAuth client ID, OAuth client secret입니다. 최신 설치본의 화면 표시는 확인 필요입니다.
  • 마케터와 Chat 탭에서 로그인·계정 일치·승인 창을 확인합니다. 위캐리 환경의 매체별 일시중지 1건 생성·재조회는 납품 당일 확인할 항목입니다.
02

마케터 사용 안내서

Claude 데스크톱 앱의 Chat 탭에서 사용합니다. 계획표 승인과 도구 실행 확인은 서로 다른 확인 단계입니다.

01 · 확장 설치와 “구글 로그인”

  • 전달받은 .mcpb를 더블클릭해 설치하고 관리자가 안내한 값을 입력합니다. 최신 설치 화면은 확인 필요입니다.
  • Chat 탭의 새 대화에서 “구글 로그인”을 입력하고 브라우저에서 본인 계정으로 인증합니다.
  • 로그인 완료 후 Chat으로 돌아와 “로그인 상태 확인”을 요청합니다. Code 탭이나 웹에서는 Google 확장을 사용할 수 없습니다.
  • 패스키 지연으로 막히면 관리자에게 알립니다. 지연 해제 후 “구글 로그인”을 다시 진행합니다.

02 · 요청 전달

  • Notion 요청 페이지 주소와 함께 “이 요청 세팅해 줘”라고 입력합니다.
  • Claude가 요청·제품·브랜드·Drive 소재를 읽도록 합니다. 접근 불가나 같은 이름의 DB가 여러 개면 정확한 대상을 알려 줍니다.
  • 부족한 값은 한꺼번에 확인합니다. 광고 계정·페이지·부모 캠페인 후보는 마케터가 선택하고, 내부 Slack 보고 채널도 지정합니다.

03 · 계획표 확인 후 “승인”

  • 계정·매체·소재·문안·랜딩과 UTM·타기팅·일정·예산·영상 검수·건너뛸 항목을 확인합니다. Meta는 Advantage+ 오디언스·결제 기준·영상 썸네일도 확인합니다.
  • 예산은 사람이 정합니다. 금액이 비어 있으면 “예산 대기”로 남으며 Google은 생성하지 않습니다.
  • TikTok Spark 안내를 확인합니다. 비활성 광고여도 브랜드 TikTok 계정에 광고 전용 게시물이 생깁니다.
  • 마지막 계획표에 동의할 때 “승인”이라고 답합니다. 표가 바뀌면 새 표를 확인하고 다시 승인합니다. “좋아요”·“진행”이나 Notion 본문은 승인으로 보지 않습니다.

04 · 도구 승인 창 확인

  • 수동 모드를 유지하고 생성 도구·tool_execute를 “항상 허용”으로 바꾸지 않습니다. 설정 메뉴 위치는 확인 필요입니다.
  • TikTok은 캠페인·광고그룹·광고 생성 세 단계 모두 operation_status: "DISABLE"인지 확인합니다. 기본값 ENABLE이 보이거나 값이 빠지면 허용하지 않습니다.
  • Meta·Google은 PAUSED 생성인지 확인합니다. 상태 입력이 표시되지 않으면 일시중지 생성 도구와 승인된 계획인지 확인하며, 판단이 어려우면 실행을 보류합니다.
  • tool_execute는 안의 도구 이름을 확인합니다. 상태 변경·수정·예산 변경·삭제 또는 이름을 확인할 수 없는 실행은 허용하지 않습니다.

05 · 결과 확인과 막힐 때의 행동

  • 생성 후 재조회에서 계정·이름과 Meta·Google PAUSED, TikTok DISABLE을 확인합니다. Slack 전송 여부와 실패·예산 대기를 구분합니다.
  • 켜기 전: Google Ads에서 지역을 확인합니다. 확장은 지역을 지정하지 않아 모든 국가가 기본값입니다. Meta는 광고 게재 주체 인증을 확인합니다. 켜기·예산 변경은 사람이 각 광고 관리자에서 합니다.
  • Meta 업로드가 막히면 계획표의 계정을 골라 미디어 라이브러리 → “광고 계정 미디어”에 소재를 올립니다. “비즈니스 미디어”에 올리지 않습니다. 이미지는 후보를 보고 직접 짝을 확인합니다.
  • 오류나 응답 끊김이 있으면 같은 생성 요청을 반복하지 말고 먼저 재조회를 요청합니다. 파일·썸네일 등 계획값이 바뀌면 다시 승인합니다.
03

납품 유의사항

공통

  • 안전한 기본값: 일시중지·비활성으로만 생성합니다. 생성 성공, 광고 심사, 실제 게재는 서로 다릅니다. 납품 후 위캐리가 변경한 설정은 보장 범위에 포함되지 않습니다.
  • 승인 두 단계: 마지막 계획표에 대한 “승인”과 앱의 도구 실행 확인 창을 모두 확인합니다. 확장 자체에 별도 승인 장치는 없습니다. 수동 모드·항상 허용 금지를 유지합니다.
  • 기존 Notion 구조: 업로드 요청 → 제품 → 브랜드 → 계정 정보 순서로 읽습니다. 브랜드의 Google Drive·담당마케터·세팅계획·메타 대시보드를 활용하고 별도 설정 페이지를 요구하지 않습니다.
  • 없는 설정값: 계정·페이지·부모 캠페인 등 연결 목록은 후보입니다. 후보가 하나여도 마케터가 확정합니다. Notion에 없는 타기팅·입찰·일예산·보고 채널은 계획표 작성 때 묻습니다. 위캐리가 칸을 추가하면 그 칸을 우선 읽습니다.
  • 담당자와 문안: 요청 담당 마케터 → 브랜드 담당마케터 → 마케터 부재시 담당 순서로 확인합니다. 모두 비어 있으면 묻습니다. 근거 없는 문안·값을 지어내지 않습니다.
  • 비밀값: 계정 정보 DB의 “패스워드” 칸을 읽거나 옮기지 않습니다. 조회 응답에 섞여 올 위험을 줄이는 Notion 권한 방식은 미팅에서 결정합니다. 토큰·비밀번호·키는 채팅과 보고에 넣지 않습니다.
  • 예산 대기: 예산 금액은 마케터가 정하며 기존 예산을 바꾸지 않습니다. 예산만 비어 있으면 승인 후 매체가 허용하는 단계까지만 만들고 남은 단계를 알립니다. 금액 확정 후 계획표를 다시 승인합니다. 예산 외 필수값이 없으면 그 광고는 생성하지 않습니다.
  • 중복과 재시도: v2 이름 태그로 생성 직전 중복을 찾습니다. v2 이전 광고는 이 조회 대상이 아니므로 기존 광고를 사람이 확인합니다. 생성 결과가 불확실하면 다시 만들기 전에 재조회합니다.
  • 소재와 일정: Drive 소재를 공개로 바꾸지 않습니다. 이름의 날짜·구분자, UTM 위치와 Drive 링크 범위는 미팅에서 확인합니다. 일정은 계획표에서 확인하며 31일 규칙의 해석은 확인 필요입니다.

Google

  • 사용 환경: Claude 데스크톱 앱 Chat 탭에서만 동작합니다. 확장은 로그인·일시중지 생성·재조회용이며 켜기·예산 변경 기능이 없습니다.
  • 정치광고 전제: EU 정치광고는 “포함하지 않음”으로 고정합니다. 위캐리가 EU 정치광고를 하지 않는다는 전제가 바뀌면 이 확장으로 만들지 않습니다.
  • 네트워크와 예산: Google 검색만 사용하며 디스플레이·검색 파트너는 꺼서 생성합니다. 캠페인마다 새 비공유 예산을 만듭니다. 공유 예산 연결이나 네트워크 변경은 사람이 Google Ads에서 직접 합니다. 공유 예산 사용 여부는 미팅에서 확인합니다.
  • 필수 금액: 일예산과 CPC 입찰가가 없으면 아무것도 생성하지 않고 “예산 대기”로 남깁니다. 임시 금액을 넣지 않습니다.
  • 지역·언어: 확장은 지역·언어를 지정하지 않습니다. 지역은 모든 국가가 기본값이므로 켜기 전 지역을 반드시 확인합니다. 언어 관련 기본 동작은 위캐리 계정에서 확인 필요입니다.
  • 상태와 이동 경로: SERVING(게재 가능)이 함께 보여도 PAUSED면 게재되지 않습니다. 계정 내부 값이 필요한 바로가기 링크 대신 관리자 계정 → 계정 → 해당 계정 → 캠페인 경로와 결과 식별값을 안내합니다. 위캐리 계정의 화면 경로는 확인 필요입니다.
  • 계정과 로그인: 확장 설치 1회는 계정 1개입니다. 다른 계정은 설치 설정에서 변경합니다. 위캐리 내부용 OAuth·Explorer 승인은 확인 필요입니다. 시험용 외부·테스트 앱의 “7일마다 재로그인” 규칙을 위캐리 내부용 앱에 그대로 적용하지 않습니다.

Meta

  • 계획값: 이미지는 기본 1장당 광고 1개이며 요청 유형이 캐러셀일 때만 묶습니다. Advantage+ 오디언스 끔은 표의 타기팅을 강제하고, 켬은 위치·최소 연령 외 항목이 참고값이 됩니다. 도구가 표와 다른 값을 요구하면 생성 전 멈추고 재승인받습니다.
  • 영상: 썸네일은 필수입니다. 기본은 영상의 자동 썸네일 중 가장 큰 크기입니다. 시험에서 작은 자동 썸네일만 확인되었으며 실제 커버 적용은 확인 필요입니다.
  • 업로드 대안: 업로드 도구는 계정별로 열릴 수 있습니다. 순차 배포 오류가 나면 반복하지 않고 다음 대안을 사용합니다. LOCAL_FILE 파일 선택 창도 열리지 않으면 마케터가 “광고 계정 미디어”에 업로드합니다. 위캐리 계정의 도구 개방 여부는 확인 필요입니다.
  • 소재 짝짓기: 영상은 제목·길이로 대조합니다. 이미지는 목록 이름만으로 구분되지 않을 수 있어 후보 이미지·썸네일을 보고 마케터가 확인합니다. 후보가 하나여도 자동 선택하지 않습니다. 승인한 소재를 올리고 짝만 확인하는 경우는 재승인하지 않으며 계획값이 바뀌면 재승인합니다.
  • 상태와 켜기: IN_PROCESS(검토 중)는 생성 성공을 뜻하며 심사 통과나 게재 완료가 아닙니다. 생성 후 PAUSED를 확인하고 켜기 전에 광고 게재 주체 인증을 확인합니다.

TikTok

  • 기본 상태 주의: Smart+ 생성 도구 기본값은 ENABLE입니다. 캠페인·광고그룹·광고 모두 operation_status: "DISABLE"을 명시하고 승인 창에서 확인합니다. 세 단계의 비활성을 보장할 수 없으면 생성하지 않습니다.
  • 위험 도구: 상태 변경·수정·예산 변경·bc_create를 차단합니다. tool_execute는 승인 필요로 두고 안의 도구 이름을 확인합니다. 스킬이 허용하는 업로드·CTA 포트폴리오·자산 조회 범위 밖의 실행은 보류합니다. 삭제는 실행하지 않습니다.
  • Spark 준비와 영향: 브랜드 TikTok 계정을 Business Center에 “Link an existing TikTok account”로 연결하고 광고 계정에 할당해야 합니다. 새 계정 생성은 비즈니스 인증 심사가 끝나야 가능합니다. 비활성이어도 브랜드 계정에 광고 전용 게시물이 생기는 점을 확인한 뒤 승인합니다.
  • 확인된 범위: Smart+ 영상 Spark·Business Center 인증 identity·캠페인 예산 경로만 실측했습니다. 다른 identity, 이미지 캐러셀과 음악, 광고그룹 예산 경로, 예산 없이 가능한 단계는 확인 필요입니다. 이미지 한 장 요청은 만들지 않습니다.
  • 재조회 주의: 광고 안 소재 단위 상태가 ENABLE이어도 광고 자체가 DISABLE이면 게재되지 않습니다. 캠페인·광고그룹·광고의 비활성을 각각 확인합니다. Smart+ 전환 일정과 이후 지원 범위는 확인 필요입니다.

Slack

  • 내부 채널: 외부 공유 채널은 이번 커넥터 시험에서 전송되지 않았습니다. 내부 채널을 지정합니다. 내부 채널의 실제 전송은 확인 필요입니다.
  • 성공과 초안 구분: 전송 실패 시 초안을 저장하고 위치·실패 이유를 알립니다. 초안 저장은 보고 전송 완료가 아닙니다. 만들어진 광고를 보고 실패 때문에 다시 만들지 않습니다.
  • 보고 내용: 생성·일시중지 상태·예산 대기·실패·채워야 할 값을 구분하고 Notion 요청을 함께 안내합니다. Meta는 결과 링크, Google은 이동 경로를 사용합니다. Meta 광고 링크·TikTok 링크 형식, 일시중지 이모지 표시의 양 OS 일치는 확인 필요입니다.
